# Contributing

Issues and PRs that improve source traceability, deterministic logic, documentation, accessibility, testing and safety are welcome. **All submitted scenarios must be synthetic** and use reserved documentation addresses/domains. Document any model use separately from hand-authored rules. Add or update tests with every behavior change, and run `npm test && pytest -q` before submitting. For security reports, follow SECURITY.md rather than disclosing a vulnerability in an open issue.
