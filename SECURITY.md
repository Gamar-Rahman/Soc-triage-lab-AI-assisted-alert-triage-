# Security policy

**Status:** educational / research demonstration only, not production-ready.

Please do not report real exploitable tenant data through public issues. Avoid uploading real event telemetry, credentials, customer data, access tokens, internal IP space, PII or confidential logs. All data in this repository must be fabricated and safe to publish.

The optional backend binds to localhost in the documented commands. It lacks authentication and production traffic controls. Do not publicly expose it. Report security concerns privately to the repository owner using GitHub's private vulnerability reporting feature if available.

Production adaptation requires threat modeling, privacy impact assessment, source integrity, identity/RBAC, abuse prevention, safe audit retention and organizational security sign-off.
